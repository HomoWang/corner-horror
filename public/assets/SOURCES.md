# Current visual asset sources

Only assets used by the active 307 two-dimensional room are kept under `public/assets/`.

| Local path | Source | Purpose |
| --- | --- | --- |
| `room307/photos/` | User-provided and project-edited room images | Fixed room views and interaction states for 307 |
| `room307/props/` | User-provided and locally prepared object images | Receipt, pencil, and safe overlays |
| `inventory-icons/` | Local renders and user-provided object images | Phone inventory thumbnails matching the room objects |

Retired 3D models, visual references, and the former branching-video pilot are preserved outside the
runtime at `production/archive/`. Their original source links and license notes are retained in
`production/archive/LEGACY_ASSET_SOURCES.md`.
